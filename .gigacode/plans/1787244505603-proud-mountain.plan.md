# Fix Build Errors

## Issue 1: `ProvisionSlot.java` — `@Builder` ignores initializing expression

**File:** `src/main/java/com/github/barbershop/provision/entity/ProvisionSlot.java`

**Problem:** Field `available = true` is initialized but Lombok `@Builder` ignores the default.

**Fix:** Add `@Builder.Default` annotation above the field.

```java
@Builder.Default
private boolean available = true;
```

---

## Issue 2: `ProvisionCategoryController.java` — cannot find symbol `AuthUtils`

**File:** `src/main/java/com/github/barbershop/account/security/AuthUtils.java`

**Problem:** The entire `AuthUtils` class is commented out — all lines start with `//`, so the class doesn't exist at compile time. `ProvisionCategoryController` imports and uses it.

**Fix:** Uncomment the `AuthUtils` class to make it a proper Spring `@Component`.
